Track marks · variety without imagery

No photography. No illustration. Still never identical.

Variety at Curi cannot come from pictures, so it has to come from a system: a small set of rules applied consistently, producing a result that looks different for every topic without ever hand-drawing anything. Every track, every avatar, every card gets an identity built from three things already inside the brand: a glyph, a typographic call number, and a geometry family.

Other variety levers already in the system04

Asymmetric grid

The exhibition grid rule already bans two adjacent panels of the same size. A dashboard of ten tracks in identical boxes reads as a spreadsheet. Vary the span, not just the mark inside it.

02

Fraunces axes

WONK and SOFT are variable, not fixed. A slightly higher WONK on a philosophy card and a lower one on a finance card is a legitimate, brand-safe way to give two subjects a different feel from the same typeface.

03

Ghost numerals

The dark feature card already places a giant, near-invisible number in the corner. Use the lesson count or the day count here instead of a static ornament, so the texture itself carries real information.

04

Motion stagger

Ten identical cards animate in with a 130ms stagger and instantly read as ten different things arriving, even before anyone reads a word.

The marquee

An always-different, always-scrolling list of real subject names is doing a lot of the "this place is full of variety" work for zero design cost.

Field vs glyph contrast

Ink field with a Paper glyph, or the reverse, is enough of a swap to make two cards on the same page read as distinct without touching colour.

How the generator actually works

  • DomainKeyword match against the topic string picks one of eight domains (Philosophy, Mathematics, History, Science, Language, Economics, Law, General). This is the only step that should eventually be a real classifier field set at curriculum generation, not client-side guessing.
  • GlyphEach domain maps to two or three glyphs from the approved set in the Brand Guidelines. A hash of the topic string picks which one, so two philosophy tracks can still look different from each other.
  • Call numberA three-letter domain code plus a hashed three-digit number, styled like a library call number. It is meaningless as data but reads as precise and cataloguing, which fits the museum-and-library metaphor already in the brand foundations.
  • FieldDomain also selects one of six geometry families from the pattern library at low opacity. Mathematics gets the blueprint grid, history gets the vitrine frame, and so on, so the texture itself is doing semantic work, not just decoration.
  • No Vermilion spendThe domain label is the only Vermilion on each mark, and a mark is one component on a page, not the page itself. Whatever page holds these still gets exactly one accent overall, not one per card.
  • StabilityThe same topic string always produces the same mark. That determinism is what makes this an identity system rather than a randomiser, users should be able to recognise a track by its mark over time.
