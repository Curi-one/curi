Track avatars · small sizes

The same mark, compressed honestly.

The full Track Mark carries three layers: a glyph, a call number, and a pattern field. Almost none of the product shows a track at full size, most of the time it's a 32px square in a list, a switcher, or a sidebar. This guide sets what survives at each size, rather than shrinking the full card and hoping it still reads.

One rule governs all of it: never fake detail that isn't legible. A pattern nobody can see is not texture, it's noise, so it gets removed rather than shrunk.

The Vermilion budget in a list04

A list of small avatars is still one screen, so the one-accent rule still applies across the whole list, not per row. Only the active or selected track may show its glyph in Vermilion, every sibling row stays in Silver on Ink. Click a row to make it active.

Square is subject, circle is person05

The token system carves out exactly one radius exception, for user avatars. Track marks never borrow it, keeping the shapes distinct means a glance at a corner tells you what kind of thing you're looking at before you've read anything.

Æ
Track mark, square, zero radius. Represents a subject.
JM
User avatar, full radius, initials only. Represents a person.

Checklist for a new small-avatar context

  • Pick the tier by sizeDon't invent a fifth size. If the slot is 36px, that's Small. If it's 20px, that's Micro. The tier defines what's allowed to render, not the other way round.
  • Never scale down the full cardShrinking the 96px mark with all three layers to 32px produces illegible text at a small size instead of a considered small mark. Always render the tier's own reduced spec.
  • One Vermilion per screen, even in a listA list of fifteen tracks is one composition. Only the selected or active row spends the accent, the rest sit in Silver.
  • Square stays squareZero radius at every tier, including Micro. The only circular avatar in the product belongs to a person, never a subject.
  • Determinism travels with the markThe same topic must resolve to the same glyph and pattern at every tier. If the dashboard tile and the sidebar row disagree, the identity system has failed at its one job.
  • Micro has no glyph, and that's fineDon't fight the 18px Fraunces floor by using a different, smaller-safe typeface just for this one case. A flat square next to a text label is a legitimate, honest answer at this size.
