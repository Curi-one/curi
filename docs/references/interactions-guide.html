Interactions & micro-interactions · v1

Motion as a second voice.

The Brand Guidelines already set three laws: Gravity, things settle, never fly in. Patience, 300ms minimum for anything meaningful. Restraint, one motion at a time. Everything below is that law applied to every real moment in the product, live and triggerable, so there is one place to check instead of guessing per screen.

The test for any new interaction: would a calm, well-edited magazine ever do this? If the honest answer is "only to grab attention," it does not belong here.

Timing & easing01

Five durations, three curves. Nothing in the product should use a value outside this set. Press the button to see the scale run.

Duration scale
micro · 100ms
hover, focus
small · 200ms
colour, opacity
medium · 350ms
entrances, modals
large · 750ms
page, stagger
xl · 1100ms
wordmark draw-in

If a duration doesn't match one of these five numbers, it's a bug, not a design choice. Never animate below 100ms, the eye reads it as a glitch rather than a transition.

The three curves
ease-out · cubic-bezier(.16,1,.3,1) — settling in. Default for anything entering.
ease-in · cubic-bezier(.4,0,1,1) — leaving. Reserved for exits.
ease-standard · cubic-bezier(.4,0,.2,1) — both directions, colour and hover states.

No spring, no bounce, no elastic overshoot, ever. All three curves are monotonic, nothing crosses its own endpoint.

Hover & press02

Every interactive surface gets exactly one property change on hover, background, border colour, or text colour, never more than one at once, always at small (200ms) or micro (100ms) duration.

Background and border move together at 200ms, the only component allowed to change two properties on hover, because both read as one "this is selectable" signal.

Feedback04

Confirmation that something happened. These should feel certain, never showy.

Progress fill
3 / 14 lessons

Width transition only, 600ms ease-out. The bar never overshoots past its target, and never animates on page load, only on an actual change.

Streak count-up
0days in a row

Digits count from 0 to the target over 700ms with ease-out, easing so the counting visibly slows into its landing number. No confetti, no burst, no colour change. The number arriving is the whole reward.

Quiz resolve

State changes at 200ms, no delay before the correct answer resolves, no suspense beat. The product never makes someone wait to find out if they were right.

Toast

Enters from 8px below at 300ms ease-out, holds 3.2s, exits at 200ms ease-in. Bottom right, never centre, centre is reserved for modals that need a decision.

Overlays05

Modal and backdrop move together but the backdrop leads by roughly 50ms, so the world dims a beat before the content arrives.

Modal open

Backdrop: 0 → rgba(ink,.72) with a 4px blur, 350ms ease-out. Box: translateY(16px)+opacity 0 → resting, 350ms ease-out, starting slightly after the backdrop. Exit reverses at 200ms ease-in with no blur fade, blur removal is expensive and reads as a stutter on lower-end phones.

Loading & the cursor dot06

Two things the Brand Guidelines name but don't fully specify. Defined here so they stay consistent wherever they're built.

Loading state

Flat Pale blocks with a slow 1600ms opacity pulse between 15% and 55%, never a moving gradient sweep. A shimmer is a gradient in motion, which the brand already rules out on type and containers alike, this keeps that rule intact under load.

Cursor tracking dot
Move here on desktop

8px Vermilion circle, follows the pointer with no easing lag inside dark, fully interactive fields only, exhibition grids, the homepage hero. Fades in at 200ms on enter, out at 200ms on leave. It is the one context where Vermilion can appear continuously rather than once, because it is attached to the pointer, not to the composition.

What never animates07

Failure modes seen in most learning products. Ruled out explicitly so nobody reaches for them under deadline pressure.

NEVERConfetti, bursts, or particle effects on streaks, correct answers, or track completion. The number or the certificate is the reward, not a screen effect layered on top of it.
NEVERA shake or red flash on an error or wrong answer. Errors already avoid red entirely, shaking the element reintroduces the alarm the colour rule was designed to remove.
NEVERSpring or bounce easing anywhere, including button presses, toasts, and modal entrances. If it overshoots its resting position, it's wrong.
NEVERParallax scrolling. Named explicitly in the Guidelines and worth repeating here since it's the first thing a new engineer tries on a marketing page.
NEVERAuto-playing or looping animation competing with reading. The marquee is the one sanctioned exception, and it sits below the masthead, never inside the lesson column.
NEVERA gradient sweep for loading states. Use the opacity pulse instead, see section 06.
NEVERMore than one element animating into view at the exact same moment outside a defined stagger group. Restraint means one motion at a time is legible, two competing motions read as noise.

Before shipping any motion

  • Duration checkDoes the number match one of the five tokens exactly? A hand-tuned 250ms or 450ms is a sign the token set is being ignored, not that this case is special.
  • Curve checkEntering uses ease-out. Leaving uses ease-in. Everything else uses ease-standard. There is no fourth option.
  • Property checkOne property animating per element under normal interaction. Two is reserved for the quiz option's combined background and border, which is a named exception, not a precedent.
  • Reward checkIf a success state needs an effect beyond a number changing or a state resolving to feel rewarding, the underlying moment is too small to be a real reward. Fix the moment, not the motion.
  • Reduced motionEvery transition and animation on this page collapses to 0.01ms under prefers-reduced-motion. That query is not optional per component, it belongs in the global stylesheet once.
  • Say it in words firstIf you can't describe the motion in one plain sentence ("the bar fills to the new width over 600ms"), it's already too complicated to belong in this system.
