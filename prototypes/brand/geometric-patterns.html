Geometric pattern library · v1

Twelve reference patterns.

Secondary imagery, built from ruled lines, grid structures, hatching and precise geometry, the architectural vocabulary of a museum or library floor plan. Always greyscale. Colour is never in the pattern itself, only ever the reveal line at the edge.

Use this page as a swatch book: check a design against the tile, copy the CSS underneath it, and adjust only the spacing values, never the logic.

ColourInk, Mid, Silver, Light, Paper only. Vermilion appears only as the reveal line, never woven into a pattern.
WeightHairlines are 1px. Emphasis lines are 2px Ink. Never a third weight in one composition.
CornersSquare, always. A pattern with a radius on it is not a Curi pattern.
RoleGeometry is texture, not subject. If it competes with the type on the same panel, reduce its opacity.
Ruled & gridded01
Ledger rules
Background texture for long text panels: the reader, changelog, ledger-style stat blocks. Keep opacity low behind body copy.
background-image: repeating-linear-gradient( to bottom, var(--light) 0 1px, transparent 1px 34px );/* row height = one line of body copy */
Column rules
Ghost 12-column grid as a standalone texture. Use to check alignment during layout, or as a faint watermark behind a hero.
background-image: repeating-linear-gradient( to right, var(--light) 0 1px, transparent 1px calc(100%/12) );
Exhibition skeleton
Wireframe for the 12-col exhibition grid, dominant panel at 5 columns. Reference this before placing any card grid, never eyeball the span.
.panel { width: calc(100%/12*5); } /* one dominant panel, dark, per grid */
Blueprint grid
Dense construction grid with corner diagonals. For technical or methodology sections, how the curriculum engine works, the spaced-repetition diagram.
background-image: repeating-linear-gradient(to bottom, var(--light) 0 1px, transparent 1px 16px), repeating-linear-gradient(to right, var(--light) 0 1px, transparent 1px 16px);
Hatching02
Fine diagonal hatch
Single-direction hatch at low opacity. Sits behind stat panels or as a subtle fill inside a badge, never behind body text.
background-image: repeating-linear-gradient( 115deg, var(--ink) 0 1px, transparent 1px 9px ); opacity: .16;
Cross hatch, on ink
Two opposed diagonals at 12% white opacity. Reserved for dark feature panels needing texture without a glyph, e.g. a quote panel.
background-image: repeating-linear-gradient( 45deg, var(--white) 0 1px, transparent 1px 12px ); /* layer a second at -45deg, same opacity */
Stepped elevation
A row of ascending bars, ruled not filled. Progress and streak visuals, curriculum-depth indicators. Final bar solid Ink marks "today."
.bar { border-top: 1px solid var(--ink); border-left/right: 1px solid var(--light); } .bar:last-child { background: var(--ink); }
Precise geometry03
Vitrine frame
Nested rectangles, museum-case logic. Frame a single stat or a pull quote to give it ceremony without adding colour.
.r1{inset:12%} .r2{inset:24%} .r3{inset:36%; border-color:var(--ink)} /* innermost ring only in full Ink */
Registration marks
Print-shop crop marks at the four corners. Certificate borders, print exports, anything meant to feel issued rather than posted.
.mark::before{ width:100%; height:1px } .mark::after { width:1px; height:100% } /* 18px marks, 14px inset from edge */
Radiating lines
Twelve lines from a centre point, sundial logic. Behind a single large stat number (streak count, day count) to give it a quiet halo.
.ray{ transform-origin: top center; transform: rotate(Ndeg); } /* repeat at 30deg steps, 1px, var(--light) */
Index ticks
Clock-face ticks inside a ruled ring, twelve positions matching the radiating pattern's angles. For loading states or a lesson-count dial.
.ring{ inset:20%; border:1px solid var(--light) } .tick{ transform-origin:center 46%; transform: rotate(Ndeg) }
Where colour is allowed04
Hover / static reveal
The reveal line
The only place Vermilion may enter a geometric composition. 2 to 4px, bottom or edge, on hover or as a static print element. A thread, not a flag.
height: 3px; background: var(--vermilion); transform: scaleX(0) → scaleX(1); transform-origin: left; duration: 350ms;

Checklist before shipping any pattern

  • Colour checkOpen the file and search for any hex outside the greyscale set. If Vermilion appears anywhere but a reveal line, stop.
  • Opacity checkPattern sitting behind text should read as texture, not shape. If you can trace individual lines from three feet away, lower it.
  • Radius checkZero everywhere. A rounded corner on a hatch tile or a vitrine frame is the fastest way to look off-brand.
  • Purpose checkEvery pattern here maps to a real idea, a ledger, a blueprint, a vitrine, a dial. Don't reach for one that doesn't fit the content's own logic.
  • Density checkOne pattern per panel. Do not stack hatch over grid over rules; pick the single form that says the most.
  • Dotted fillNever use a dot grid as a background pattern. Halftone dots exist only as a texture layer on the dark glyph cards, nowhere else.
